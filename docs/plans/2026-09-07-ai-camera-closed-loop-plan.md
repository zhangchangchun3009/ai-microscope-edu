# N-117M AI 相机一体机改造计划

> 状态：**决策已冻结**（2026-09-07，与原硬件开发周六对齐）  
> 产品线：合作学校 **AI 赋能教学显微镜**（无电控）。后期另开「高端电控版」与「云端教材样本训练」。  
> 工程入口：[`../../AGENTS.md`](../../AGENTS.md)  
> 本仓位置：`ai-microscope-edu/`（先挂在 `ai-microscope-design` 工作区方便对照旧栈；功能稳定后再整仓移出）  
> 取代：根目录 [`docs/plans/2026-08-25-n117m-hardware-retrofit-plan.md`](../../../docs/plans/2026-08-25-n117m-hardware-retrofit-plan.md) 中的 **XYZ 电机化**。相机盒 / 三目光路结论仍有效。

**一句话目标：** 永新 N-117M 三目 + 野火 LubanCat-3BTB（RK3576）+ pc-oic678，做成 **10 寸触屏闭环一体机**：学生手拧 XYZ，软件负责预览、语音问答、识图、计数、手动引导的 Z 融合与扫描拼接。

**开发窗口：** 约 **4 周** 出可进教室的样机。人数 **两人**（你 + 本助手）。**先硬件、后软件，不并行。** 本周（2026-09-08 起）只做结构；软件等挂载件差不多再开工。不在本期做 Agent 工具循环、RP2040、平板/远程客户端。

## 1. 为什么改

合作学校买的是 **AI 上课能力**，不是载物台伺服。电机化要卡尺、打印、皮带、标定、抗振，周期长，且 N-117M 上手拧已经够用。

上一版软件（scandog 多进程 + MicroClaw 网关 + Flutter 双 WS + 工具循环 Agent）对「无电机、单屏一体机」过重：课堂问答被工具/技能拖慢，平板链路在教室里是负担。

保留的价值：UVC 预览、拍照、ROI 问 AI、快速问答、Z 堆叠算法、XFeat 拼接、配网/关机、语音 ASR/TTS、计数模型。

## 2. 产品形态（教室里长什么样）

```
        10" 触屏（斜向，镜臂与观察头之间）
              │
  目镜 ── 三目头 ── 摄影口 + 打印相机盒 + pc-oic678
              │
           铸铁镜臂
              │
        顶丝抱箍 ── 矩形板 ── 打印主板盒（RK3576 + 喇叭）
              │
        载物台（学生拧 XY）     粗微手轮（学生拧 Z）
              │
             底座 LED（手拧亮度）
```

上课主路径：放片 → 手拧找视野/对焦 → 触屏看预览 → 按住说话问「这是什么」或框 ROI → 听讲解 / 看字幕 → 需要时开「景深融合」或「拼接」向导，按提示拧一格拍一张 → 出图。

**验收样机（4 周末）：**

1. 开机进全屏教学 UI，看不到普通桌面。
2. 预览延迟可上课（目标本机直出，不经浏览器）。
3. 语音问答 + 字幕；ROI 识图能出教学向的描述。
4. 手动 Z 融合、手动网格拼接能出图（允许不如电控整齐）。
5. 计数能在典型血涂片/植物表皮上给出个数（权重到位为前提）。
6. 触屏能配 Wi-Fi、能关机。
7. 盒子能挂在臂后，线不挡手轮和载物台行程。

## 3. 硬件（无电机；本周是主战场）

### 3.1 沿用

| 件 | 说明 |
|----|------|
| N-117M 三目整机 | XYZ / 聚光 / 亮度全部手拧 |
| pc-oic678 + 打印相机盒 | `hardware/n117m/`；φ25 滑套 + 原厂 M4 顶丝 |
| LubanCat-3BTB | USB 相机、MIPI 屏、板载麦、3.5mm 或板载功放接双喇叭；板侧适配器给整机 |
| 底座 S-LED | 铭牌 **INPUT DC 5V / 10VA**。样机可先继续用原适配器；目标是 **灯吃板的 5V**（§3.6），不要反过来让灯的适配器养 RK3576 |

### 3.2 停工（移到高端电控版）

剖分皮带轮、XY/Z 电机抱箍、RP2040、嘉立创驱板、`pulses_per_um` 标定、倾角矩阵。`scad/05_pulley_split.scad` 等保留在目录里当归档，不继续打。

### 3.3 本周要出的件：镜臂精细模型 + 主板盒 + 连接件

从 **2026-09-08（周二）** 起只做这些，不写应用代码。目标：**本周日以前结构能总装预览；能打的打试件，打不完至少 STL/尺寸冻结。**

| 件 | 作用 | 建议文件 |
|----|------|----------|
| 镜臂精细模型 | 抱箍贴合、总装干涉、屏/盒位置参照 | 已有 `scad/20_arm.scad` + `10_layout.scad`，按实拍/卡尺继续收 |
| 主板盒 | 装 LubanCat-3BTB、喇叭、走线、散热 | 新 `scad/50_board_box.scad`（OpenFlexure 电器仓为胚，按板实测开孔） |
| 臂后抱箍 | 顶丝扣镜臂 | 新 `scad/51_arm_clamp.scad` |
| 连接矩形板 | 4 孔拧盒子 | 可与抱箍同文件或 `52_box_plate.scad` |
| 屏支架 | 斜向、小托盘（§3.4） | 本周至少出结构方案和占位模型；孔位不够就先占位 |

重量靠近底座，不要把整盒吊在调焦齿条上。材料 PETG/ABS，层高 0.16–0.20。

**你侧卡尺（越早越好）：** 板长宽高、接口朝向、安装孔；臂后宽度与可贴平面；盒到目镜/手轮干涉。屏套件背面有无螺孔、厚度、排线方向（§3.4）。

OpenFlexure 电器仓 SCAD 若本工作区没有，从旧打印仓拷入 `hardware/ref/openflexure-electronics/`。

### 3.4 10 寸屏怎么固定（待与你一起定结构）

约束：打不出一块和屏幕一样大的支撑板；希望斜向放在镜臂与观察头之间。

候选（定案前不打正式件）：

| 方案 | 做法 | 风险 |
|------|------|------|
| A 小托盘 + 结构胶 | 打印小于屏的托 + 两侧耳，胶粘屏背 | 胶失效、维修难、散热 |
| B 小托盘 + 屏厂孔 | 若 10 寸套件背面有螺孔，打印短臂对拧 | 要先量套件 |
| C 铝条/折弯支架 + 打印接头 | 金属承重，打印只做抱箍和关节 | 外观和采购 |

**建议先量屏幕套件背面**（有无 VESA/原厂孔、厚度、排线方向），再选 B；没有孔再在 A/C 里选。排线必须从 MIPI 座走到臂后盒子，留应变环，避免拧 Z 时扯线。

### 3.5 光路提醒（软件标尺要用）

三目摄影口 **无 16× 目镜**。10× 物镜 + 约 1× 接口、IMX678 1/1.8″、预览 1440×1080 时，视场大约 **580×435 μm**（未用测微尺，±20%）。前端默认 `magnification=20` 的 100 μm 尺 **作废**，本期用测微尺标一次 `um_per_px`。

### 3.6 照明 5V 接到板子（低优先级）

镜臂后已有 **DC 5V 圆孔座** 给底座 S-LED。电压与鲁班猫 5V 逻辑电源相同，可以把灯接到板子上，少带一只镜体墙插。

- **方向：** 板（或其适配器的 5V 总线）→ 灯。**不要**用镜体原装 5V/10VA 适配器给 RK3576 + 10 寸屏 + UVC 供电，铭牌功率只够灯。
- **取电点：** 量 LubanCat-3BTB 上标注 5V 且能持续供电流的排针/焊盘/电源输入并线，再引到臂后圆孔座（注意极性）。不要用带过流保护的 USB 口硬灌 2A 级负载。
- **电流：** 10VA @ 5V ≈ **2A** 给灯。加上板、屏、相机、喇叭后，整机适配器要按实测余量选（先按 ≥5A @ 5V 估，装上再测）。电压跌了先把灯改回独立适配器，不挡上课。
- **控制：** 仍用底座拨轮和船型开关；本期 **不做** GPIO/PWM 调光。
- **排期：** 不进本周硬件门禁，也不挡软件开工。盒子预留过线孔即可；挂载件打完有空再焊。

## 4. 软件架构

### 4.1 原则

- **一块板、一个教学进程** 为主 UI；算法/相机在同进程线程或极少数本地 worker。不要 scandog 九服务 + 网关 + 双 WS。
- **触屏 = Linux 桌面应用（kiosk）**，不是浏览器，不是 Flutter 平板。推荐 **Python + PySide6**（与相机/算法同语言，一个月内能闭环；RK3576 上 Flutter embedder 风险大）。
- **AI 本期用 Python。** 云端 LLM 走 HTTP 流式；板上 NPU 只跑计数/清晰度等已有 RKNN。不引入 microclaw，不引入 rmcp。若问答客户端日后要独立进程，再评估薄 Rust，不作为 W1 依赖。
- 旧实现 **只读对照**：`microscope/` 的 cam/algo/audio/mipi-hmi，`microclaw` 的快速问答，`board-algo-import` 的堆叠与拼接。

### 4.2 模块（目录与设计章节一一对应）

```
ai-microscope-edu/
  AGENTS.md
  docs/plans/          # 本文件
  hardware/            # 打印件与卡尺；N-117M 图档（由你迁入）
  software/
    app/               # §4.3 入口：kiosk、页面调度，无业务细节
    camera/            # 预览、拍照、ISP 控件（无人值守回写）
    capture_guide/     # 手动 Z 融合向导、手动拼接向导
    algo/              # focus_stack、mosaic（从旧 algo_service 移植）
    vision/            # ROI、计数（分割+分类）
    qa/                # 快速问答、会话、知识库、识图提示
    voice/             # ASR / TTS；字幕与语音共用同一转写
    system/            # Wi-Fi 配网、关机、亮度、kiosk 自启
    models/            # RKNN/权重（不进 git LFS 以外的大文件策略另定）
    tests/
```

进程关系：

```
systemd（kiosk 用户）
  └── edu-app（PySide6 全屏）
        ├── camera 线程：UVC → 预览控件 + 抓帧
        ├── algo worker：融合 / 拼接 job
        ├── vision worker：计数 RKNN
        ├── qa：云端 LLM 流式（零工具）
        └── voice：板载麦 → ASR；TTS → 双喇叭
```

长任务（融合、拼接、计数）用 **job_id + 状态查询**，界面进度条，禁止忙轮询摄像头。

### 4.3 入口层

`software/app/` 只做：启动全屏、导航（预览 / 问答 / 向导 / 设置）、把按钮接到各模块接口。预览渲染、LLM、拼接细节不进入口文件。

### 4.4 相机

- 直接 v4l2 / GStreamer（或薄封装 ffmpeg），本机显示。默认 1920×1080，若沿用 4:3 裁剪则在本模块一次做完。
- **禁止 IsoLock / 禁止按帧统计改显示矩阵。** 饱和度等由设置页调节；「恢复默认」读 `camera_defaults` 一次下发。pc-oic678 出厂饱和 110 可当「接近目视」的默认，70 不再当黄金值。
- 拍照写入本地 `var/captures/`。

### 4.5 手动 Z 融合（替代自动对焦）

窗口流程：

1. 学生先手拧到自认最清。
2. 选层数（默认 5）与「每层拧微调大约一格」的文案（格值 4 μm，文案用「一格」不要用电机步）。
3. 每层：提示方向 → 学生拧 → **拍一张**（可重拍）→ 下一层。
4. 结束：`algo.focus_stack` 出全焦图，可再送问答/计数。

没有编码器，层间距是提示不是闭环。融合允许因手拧不均而发糊，UI 写明。

### 4.6 手动扫描拼接

窗口流程：

1. 选网格（默认 2×2 / 3×3，上限先 5×5）。
2. 当前格高亮；提示「向右/向上移动，让画面重叠大约三分之一」（10× 下约 0.2 mm 量级，用「重叠一块」口语即可）。
3. 拍瓦片，可重拍；蛇形顺序与旧扫描一致，降低学生记路径的成本。
4. 结束：`algo.mosaic`（XFeat / 现有 native 路径能移植则移植）。失败时保留瓦片文件夹，允许只导出未拼图。

不调 motion API。重叠全靠学生，拼接必然不如电控——产品文案承认这一点。

### 4.7 问答与识图

对照 `docs/superpowers/specs/2026-08-17-fast-qa-conversation-mode-design.md`，**只吸收问答槽**：

- 零工具、短系统提示、知识库每轮最多 2 条预注入、思考关闭、流式 + 非流式回退。
- 目标：首 token 可上课（云端网络允许时力争数秒级）。
- 会话：内存 + 本地少量会话文件（「几张」）；不做操作 Agent、不做 microscope-cli。
- 识图：当前帧或 ROI 裁图作为多模态消息；ROI 画在预览上（旧标注协议可参考，传输格式自定，不必兼容 Flutter WS）。

语音与字幕是同一套 turn：ASR 文本既可显示也可再编辑后发送。

### 4.8 计数

- 输入：当前帧或 ROI。
- 流水线：分割 → 分类 → 个数 + 简表（类别、置信度）。能画框/掩膜叠在预览上则叠。
- 权重：上一版未进仓。**第 1 周必须从原开发拿到 RKNN/ONNX 与类别表**，放入 `software/models/`（git 策略：小文件进仓，大文件板端或对象存储）。
- NPU 与融合/拼接互斥：同时只跑一个重推理。

### 4.9 语音

复用板上已验证的 SenseVoice（ASR）+ 现 TTS 管线思路，改为本应用库调用，不单独 `audio_service` 端口。无外接平板仍要「听到回答」。默认不弹出键盘；字幕开时给文本框。

### 4.10 配网与关机

从 `mipi-hmi-service` 抽 nmcli 扫网 / 连 Wi-Fi（含 802.1X 若旧实现已有）/ 关机。做成设置页两个按钮，不要开机先全屏配网（未联网时在设置里红点提示即可）。kiosk 账号无桌面、应用 systemd `Restart=on-failure`。

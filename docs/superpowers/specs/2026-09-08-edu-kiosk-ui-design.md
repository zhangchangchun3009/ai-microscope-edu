# 教学一体机 kiosk UI（总体）

> 状态：设计已与用户对齐（2026-09-08）  
> 产品计划：[`../../plans/2026-09-07-ai-camera-closed-loop-plan.md`](../../plans/2026-09-07-ai-camera-closed-loop-plan.md)  
> 实现目录：`software/`（入口 `app/`，向导 `capture_guide/`，问答 `qa/`，语音 `voice/`，系统 `system/`）  
> 对照（只读）：旧 Flutter 分屏与 PTT；MicroClaw 快速问答槽。不抄进程拓扑、不引入对话面板打字。  
> 本文件是 **UI 与交互总规**。像素级控件、提示词、GStreamer 接法在实现计划里再拆，开发中缺细节再问。

## 1. 目标

10 寸 MIPI 触屏、无桌面 PySide6 全屏。学生手拧 XYZ，对着预览用语音问标本；需要时框选、计数、按计划手拍再融合或拼接。学生主路径 **不打字**。

211 已验证：停 scandog 后 `linuxfb` 可独占屏。面板 framebuffer 为 **1080×1920 竖屏**；产品方向用设置里的旋转纠正，不在本文件锁死安装角度。

## 2. 依赖与边界

- 真源在 Mac 工作区 `ai-microscope-edu/`。211 是部署与点验板；**235 不部署、不改旧栈**。
- 无相机时预览为占位（色块 +「等待相机」）。工具栏、向导状态机、历史、设置必须可在占位下点击。拍照格在无相机时按钮禁用并提示，或写入夹具 JPEG（开发用）。
- 禁止：对话面板键入发送、开机全屏配网、扫描过程自动 Z 融合、motion API、IsoLock、把 mipi-hmi 进程和 Qt 同时占屏。
- 相对产品计划的收紧：计划写「开字幕后允许改字」；本期 **学生问答路径不能用键盘发送**。设置里的系统提示词（以及若做了知识库管理页）是教师配置，可以用触屏键盘。

## 3. 主画面壳

预览铺满。右侧 **工具条** 常驻，可展开或折成窄边（一条折叠柄）。展开后展示全部功能入口（大触摸圆）。

| 入口 | 位置 | 打开后 |
|------|------|--------|
| AI 浮标 | **不进工具条**，可拖动，叠在预览上 | 见 §4，无面板 |
| 标注 | 工具条 | 仍全屏预览，画 ROI |
| 计数 | 工具条 | 仍全屏预览，当前帧或 ROI 出数并叠图 |
| 融合 | 工具条 | 分屏 + 拍照计划（§6.1） |
| 拼接 | 工具条 | 分屏 + 拍照计划（§6.2） |
| 历史 | 工具条 | 分屏 + 只读会话（§7） |
| 设置 | 工具条 | 分屏 + 分组列表（§8）。配网、关机、字幕、旋转、ISP、问答提示词都在这里 |

浮标默认贴预览 **右侧垂直居中**（在工具条内侧），避免挡住标本中心。按当前预览宽高计算，不假设屏已旋转。位置记在本地，下次开机恢复；旧版无版本号的左上角存档视为无效，改用该默认。

## 4. 语音与字幕

- **按住浮标录音，松开发送**（与旧前端 PTT 相同）。单次最长 **300 s**：超时自动停录并按已录内容发送；过短或静音则丢弃并语音提示。阈值与板载 ALSA 见 [`2026-09-10-board-voice-io-design.md`](2026-09-10-board-voice-io-design.md)。ASR → 快速问答 → TTS 见 [`2026-09-10-voice-qa-turn-design.md`](2026-09-10-voice-qa-turn-design.md)（流式分句队列、开播水位 2～3 句；知识库只留接口；字幕条与识图不在该刀）。
- **单击浮标不弹窗**，避免与拖动、长按抢手势。
- 回答只走 TTS：流式分句入队，**攒够 2～3 句（或生成结束）再开播**，上一句喇叭结束再播下一句。从按住录音到本轮队列播完（或失败 beep），浮标 **禁用**，不能再按住。
- 字幕总开关在 **设置**，默认关。打开后屏幕 **底部一块最多两行的透明只读框**（不是上下分栏）：ASR 出字即显；TTS 按句顶替；超长切幕；喇叭结束即隐藏。细则见 [`2026-09-14-edu-settings-design.md`](2026-09-14-edu-settings-design.md) §6。关字幕则主界面除工具条图标外无问答文字。
- 识图：若当前有 ROI 则送裁图，否则送当前帧。无相机则本轮不加图，语音仍可问并提示「无画面」。

## 5. 分屏

标注、计数 **不** 分屏。融合、拼接、历史、设置打开时：

- 左预览、右操作，默认宽度 **1:1**；工具条仍在最右缘。
- 中间分割条 **手指可拖**，改变左右比例（钳制在 25%–75%）。现壳 handle 过窄，设置刀里加宽到可点。
- 浮标仍叠在 **左侧预览** 上，分屏时也能按住说话。
- 关闭右栏（向导完成/取消、历史返回、设置关闭）后恢复预览铺满。

## 6. 拍照计划

右栏先填参数，确认后生成 **空格子**。每格：未拍显示「拍照」；已拍显示缩略图 + 删除。删格后恢复「拍照」。全部计划格都有图之后，「开始融合」或「开始拼接」才可点。

照片落盘 `software` 运行时的 `var/captures/<job_id>/`（JPEG）。界面 **只保留缩略图**（长边约 256 px）。算法从文件读，禁止把全部满分辨率帧同时解码进 RAM。预览始终只有当前一路。

无相机：格内拍照不可用；开发可用夹具文件写入格子以测状态机。

### 6.1 融合（独立功能）

只问 **层数**（默认 5）。格子按拍摄顺序编号 `1…N`（一维，不蛇形）。同一视野，文案提示每层大约拧微调「一格」，不对编码器闭环。层间发糊写明可接受。

### 6.2 拼接（扫描不做融合）

只问网格：默认提供 2×2、3×3，上限 **5×5**。每格一张，学生对着该格自己对焦。 **扫描流程不调用融合。**

格子 **蛇形编号**，起点左上，奇数行（从上往下第 1、3、5 行）从左到右，偶数行从右到左。例如 3×3：

```
1 2 3
6 5 4
7 8 9
```

文案提示向下一格移动时「重叠大约一块」，不用微米数。失败时保留瓦片目录，允许不拼只留下原图。

## 7. 历史与会话

会话 **不是**「启动一次应用一场」。kiosk 可全天不退出。

- 连续问答算同一场；约 **20 分钟** 无问答则自动新开。
- 历史页可手动「新对话」。
- 布局（在分屏右栏内）：左侧会话标题列表，右侧该场只读正文。对标常见文字 AI 应用（如 DeepSeek 客户端）的主从栏，而不是聊天输入框。
- **不能** 在历史里打字发送。
- 产品要的是 **有记录、能回看**。会话切分从简。
- 发给 LLM 的上下文按模型窗口截断（只带最近若干轮）；本地文件可留得更长。磁盘保留最近 **20** 场，超出删除最旧文件。

## 8. 设置

右栏常规分组列表，不另发明交互。配网、关机不进主工具条。

首刀范围与立刻旋转、混音器启动、音量/字幕/提示词/LLM 见 [`2026-09-14-edu-settings-design.md`](2026-09-14-edu-settings-design.md)。屏旋转必须立刻转（画面与触点一起），缺省 **90° 横屏**。简单配置用一份 `var/edu.yaml`（可写注释）；混音器固定通路不进设置 UI。LLM 密钥按本机 CPU 序列号加密，界面不回显明文。

- 显示：字幕开/关；屏旋转（0/90/180/270，纠正竖屏 framebuffer）
- 语音：喇叭音量（ALSA Output）；spk / Line 2 / PGA 等通路由服务启动写入
- 问答：自定义系统提示词（§8.1）；LLM 连接（yaml 的 `llm` 段）；知识库管理 UI 为可选（§8.2）
- 相机：ISP 手调 + 恢复默认（无相机时控件禁用）——**首刀不做**
- 网络：Wi-Fi 扫网/连接（从 mipi-hmi 的 `wifi_manager` **拷逻辑**，不跑 mipi-hmi 进程）。未联网在设置入口红点，不强制先配网——**首刀不做**
- 电源：关机（确认后 `systemctl poweroff` / 现有 polkit 路径）——**首刀不做**

### 8.1 自定义系统提示词（要做）

设置 → 问答 → 打开多行编辑窗口（触屏键盘）。文案可用「自定义问答助手」。

- 只作用于快速问答的 system 尾部（领域短提示 + 当前时间 + 本段），不写操作 Agent / 工具规则。
- 存储在本应用数据目录（例如 `var/qa/USER.md`），OTA/升级不得覆盖。不使用 `~/.zeroclaw/`。
- 注入上限 **1000** 字（与旧 `USER_PERSONA_MAX_CHARS` 相同）：磁盘可存更长，送模型时截断。空内容则不加该段。
- 保存后下一轮问答生效。清空需确认。

### 8.2 知识库（导入能力必做；触屏管理可后做）

问答每轮最多预注入 **2** 条（计划已有），检索失败则不注入，照常生成。本地表由 `qa/` 维护（SQLite 即可）。

合作学校要用程序把已有知识库灌进设备。本期提供 **本应用自己的 HTTP 导入**（教学进程内嵌，**不启 microclaw、不复用 42617/旧网关路径**）。路径、端口、JSON 字段到做 `qa/` 时另定，再给学校一份短说明。旧仓 `POST /api/integration/kb/import` 只作需求对照，不当前契约。

**触屏「知识库管理」**（列表 / 增删 / jsonl）排期不够就砍掉。砍掉时设置里写一句：用学校系统经 HTTP 导入。

## 9. 模块与进程

一个 systemd 用户服务拉起教学进程（可替换当前 `edu-kiosk-probe`）。`app/` 只调度壳、分屏、工具条、浮标。

| 行为 | 模块 |
|------|------|
| 预览占位 / 日后 UVC | `camera/` |
| 拍照计划状态机、蛇形编号 | `capture_guide/` |
| 融合 / 拼接算法 | `algo/`（job_id + 查询进度） |
| ROI、计数 | `vision/` |
| 快速问答、会话文件、截断、USER.md、知识库表、学校导入 HTTP | `qa/` |
| PTT、ASR、TTS | `voice/` |
| nmcli、关机、旋转、kiosk unit | `system/` |

长任务禁止忙轮询摄像头。融合与拼接与计数占用 NPU 时互斥（计划已有）。

## 10. 测试

- **先测后实现**（状态机、蛇形编号、会话空闲切场、上下文截断、缩略图不持有原图路径约定、USER.md 注入截断）。知识库 HTTP 的字段与幂等到做该模块时再写测。
- 纯 Qt 布局、linuxfb、触屏在 211 点验，不强制 pytest。
- 声称壳层可点前：Mac 或 211 跑相关 pytest，并写明命令。

## 11. 非目标（本 spec 不展开）

相机 GStreamer / eglfs、计数权重与类别表、出厂领域短提示的最终措辞、ROI 手势像素细节、屏支架、电控、触屏知识库 CRUD、知识库 HTTP 的路径与 JSON（做 `qa/` 时另定）。实现到某一块时另开小节或另写 plan。
